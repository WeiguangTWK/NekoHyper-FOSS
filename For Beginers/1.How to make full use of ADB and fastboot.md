# Install Platform-Tools

Platform-Tool contains fastboot and adb tools

## Download

Check Platform-Tools [Here](https://developer.android.com/tools/releases/platform-tools)

Check Device-Driver [Here](https://adb.clockworkmod.com/)

Extract at the place you want to store the Platform-Tools binary and start a command shell, and then you can use adb and fastboot by directly run

```command prompt
fastboot <parameters>
```

```command prompt
adb <parameters>
```

For newcomers I would recommand two GUI tool that can help you make use of ADB/Fastboot with convenience

[AShell You](https://github.com/WeiguangTWK/aShellYou): A powerful ADB(Shizuku)/Root shell interface for Android and it has the most complete adb command list for you to look up.

[Autumn Box](https://atmb.top/): A classic all-in-one toolbox for PC

[Fastboot Enhanced](https://github.com/libxzr/FastbootEnhance): GUI interface for Fastboot and can help you use Fastboot with ease

In the following I will list some not all of the commands
For some one who is interested in Android shell commands, look up AShell You

## ADB Command list

```shell command
adb reboot fastboot
adb reboot recovery
```

**remember it** Reboot to fastbot or recovery

```shell command
adb devices
```

list android devices that connected to your devices

```shell command
adb -s <serial_number> shell
```

Enter shell interface of certain device

```shell command
adb install [-lrtsdg] <path_to_apk>
```

install APK

```shell command
adb uninstall <package_name>
```

uninstall apps

```shell command
adb push <local> <remote>
```

send certain file to device

## Fastboot Commands

dangerous to use and could corrupt your device, use it after you know what will it do

```shell command
fastboot boot <path_to_boot.img>
```
temporarily boot from specified boot image before next boot

```shell command
fastboot flash <partition> <path_image>
```

flash image into specific partition

```shell command
fastboot set_active <a/b/other>
```

set the active slot for VAB/AB devices

```shell command
fastboot reboot fastboot
```

reboot to Fastbootd
