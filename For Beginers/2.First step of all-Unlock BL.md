## Brand that doesn't need key to unlock

>Devices should deny the fastboot flashing unlock command unless the get_unlock_ability is set to 1. If set to 0, the user needs to boot to the home screen, open the Settings > System > Developer options menu and enable the OEM unlocking option (which sets the get_unlock_ability to 1). After setting, this mode persists across reboots and factory data resets. [Source Article](https://source.android.com/docs/core/architecture/bootloader/locking_unlocking?hl=zh-cn#unlocking-bootloader)

Some phone brands (`Pixel`, `One Plus` etc) don't require a key code to unlock Bootloader.
Go to `DevelopmentSettings` of `Settings` and find `OEM Unlock`, enable it

Then as what mentioned above, we should now head for Bootloader Mode
